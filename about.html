My Story

Halo, saya Marshel.

Saya mahasiswa Teknik Komputer yang tertarik pada software engineering, artificial intelligence, embedded systems, dan robotics. Saya belajar dengan membangun proyek nyata—mulai dari web application dan backend API, hingga computer vision dan perangkat berbasis ESP32.

Bagi saya, teknologi paling menarik ketika beberapa bidang saling terhubung: antarmuka web jadi pusat monitoring, API menghubungkan data, model AI membaca kondisi, dan mikrokontroler berinteraksi langsung dengan dunia fisik.

Fokus saya adalah memperkuat fondasi, mendokumentasikan proses belajar, dan terus meningkatkan kualitas setiap sistem yang saya bangun.
