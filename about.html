My Story

Halo, saya Marshel.

Saya mahasiswa Teknik Komputer yang tertarik pada software engineering, artificial intelligence, embedded systems, dan robotics. Saya belajar dengan membangun proyek nyata—mulai dari web application dan backend hingga computer vision dan perangkat berbasis ESP32.

Bagi saya, teknologi paling menarik ketika beberapa bidang saling terhubung. Sebuah antarmuka web dapat menjadi pusat monitoring, API menghubungkan data, model AI membantu membaca kondisi, dan mikrokontroler berinteraksi langsung dengan dunia fisik.

Saya belum berhenti pada satu label keahlian. Fokus saya adalah memperkuat fondasi, mendokumentasikan proses, dan terus meningkatkan kualitas setiap sistem yang saya bangun.
