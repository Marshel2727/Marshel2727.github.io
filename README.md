# 🌐 Website Portofolio Pribadi

Repositori ini berisi kode sumber untuk website portofolio pribadi yang dibuat menggunakan HTML5 dan CSS3.

🔗 **Live Demo:** [https://marshel2727.github.io/](https://marshel2727.github.io/)

---

## 📌 Halaman Website

Website ini terdiri dari beberapa halaman utama:
* **Home (`index.html`)**: Halaman beranda utama menyambut pengunjung.
* **About (`about.html`)**: Halaman profil, latar belakang, dan keahlian.
* **Project (`project.html`)**: Galeri proyek atau karya yang pernah dikerjakan.
* **Contact (`contact.html`)**: Informasi kontak untuk terhubung.

---

## 🛠️ Teknologi yang Digunakan

* **HTML5**: Struktur semantik halaman web.
* **CSS3**: Styling tampilan responsif dan navigasi.

---

## 🚀 Cara Menjalankan Secara Lokal

1. Clone repositori ini:
   ```bash
   git clone https://github.com/Marshel2727/Marshel2727.github.io.git
   ```
2. Buka folder proyek dan jalankan `index.html` langsung di browser favorit kamu (Chrome, Edge, Firefox, dll.).
