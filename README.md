# Portfolio Marshel

Website portofolio pribadi Marshel, mahasiswa Teknik Komputer yang membangun proyek di bidang web, AI, computer vision, IoT, dan embedded systems.

**Live demo:** [https://marshel2727.github.io/](https://marshel2727.github.io/)

## Halaman website

- **Home (`index.html`)**: Identitas utama, proyek yang sedang dibangun, tech stack, journey, dan minat teknis.
- **About (`about.html`)**: Cerita pribadi, arah belajar, dan perjalanan sebagai mahasiswa Teknik Komputer.
- **Projects (`project.html`)**: Case study Entok Monitoring, Vision Entok, Mars Web Translator AI, dan eksperimen lainnya.
- **Contact (`contact.html`)**: Informasi kontak untuk terhubung.

## Teknologi

- **HTML5** untuk struktur semantik dan aksesibel.
- **CSS3** untuk layout responsif, komponen, dan tema espresso-latte.
- **Tanpa framework** agar website statis tetap ringan dan dapat dipublikasikan langsung melalui GitHub Pages.

## Menjalankan secara lokal

Clone repository berikut:

```bash
git clone https://github.com/Marshel2727/Marshel2727.github.io.git
```

Kemudian buka `index.html` secara langsung atau jalankan static file server dari folder project.
