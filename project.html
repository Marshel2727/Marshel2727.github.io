02

AI · Computer Vision

Entok Vision

Desktop lokal

Aplikasi desktop untuk penyaringan awal kondisi mata entok dari CCTV RTSP atau webcam menggunakan YOLO.

Python YOLO OpenCV ONVIF
Tantangan
Memproses aliran kamera secara stabil sambil menjaga hasil AI sebagai penyaringan awal, bukan diagnosis.
Yang dibangun
GUI desktop, input RTSP/webcam, pemilihan model, penyimpanan screenshot, dan kontrol PTZ melalui ONVIF.
Kontribusi
Integrasi inference, sumber kamera, antarmuka desktop, pengujian, dan packaging Windows.
Status & bukti
Source, konfigurasi training, test, serta script build CPU/GPU tersedia di repository.

03

AI Lokal · Penerjemahan

Mars Web Translator AI

v0.3.0-dev.1

Penerjemah dokumentasi teknis lokal yang mempertahankan kode, command, URL, dan istilah teknis tanpa mengirim isi halaman ke layanan cloud.

Extension MV3 FastAPI Ollama Qwen3 8B
Tantangan
Menerjemahkan teks teknis sambil menjaga code, command, URL, placeholder, dan nama API tetap utuh.
Yang dibangun
Extension Chromium, API FastAPI lokal, pipeline Ollama/Qwen3, cache browser dan SQLite, glossary, serta validasi output.
Kontribusi
Integrasi extension, kontrak API, workflow model lokal, autentikasi localhost, dan QA hasil terjemahan.
Status & bukti
Versi development dengan GPU wajib; arsitektur, test, roadmap, dan source tersedia di repository.
